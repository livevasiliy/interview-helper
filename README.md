# Interview Helper

Приложение для macOS (меню-бар): слушает интервью, распознаёт речь, находит вопрос интервьюера и показывает подсказку для ответа в плавающем окне. Умеет анализировать экран (например, задачу для live coding) и отвечать на вопросы, введённые вручную.

Своего сервера нет: вы подставляете собственные API-ключи (они хранятся в Связке ключей).

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/livevasiliy/interview-helper/main/scripts/install.sh | bash
```

Скрипт скачивает последний релиз, проверяет контрольную сумму SHA-256, копирует приложение в `/Applications` и запускает его. Конкретная версия: `... | VERSION=v0.2.0 bash`. Сначала прочитать скрипт: [scripts/install.sh](scripts/install.sh).

Требуется macOS 13 или новее. Приложение подписано сертификатом разработчика, но **не нотаризовано** Apple. Установка через `curl` не ставит карантин, поэтому macOS его запускает; DMG, скачанный браузером, придётся открывать через правый клик → «Открыть».

При первом запуске разрешите **Микрофон** и **Запись экрана** (нужна, чтобы слышать звук собеседника и делать скриншоты; видео не записывается).

## Обновления

Раз в несколько часов приложение в фоне спрашивает у GitHub последний релиз (один анонимный запрос, ничего о вас не отправляется). Если вышла новая версия, в меню иконки появится пункт «Обновить до …». Ничего не ставится без вашего подтверждения; отключить проверку можно в Настройках → Обновления. Вручную обновиться можно той же командой установки.

## Ключи

- **Подсказки:** Google Gemini (бесплатный или платный ключ, [aistudio.google.com/apikey](https://aistudio.google.com/apikey)), Groq, OpenRouter, Ollama (локально), OpenAI, Anthropic.
- **Распознавание речи:** Deepgram ($200 бесплатно при регистрации), Groq Whisper (бесплатный тариф), OpenAI.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| ⌃⌥Space | начать / остановить прослушивание |
| ⌃⌥↩ | ответить сейчас |
| ⌃⌥S | проанализировать экран |
| ⌃⌥O | показать / скрыть окно |
| ⌃⌥, | настройки |

## Приватность и правила

Звук уходит в выбранный сервис распознавания, вопросы, история и текст из «О себе» — выбранному провайдеру подсказок (бесплатные тарифы могут использовать данные для обучения; Ollama работает локально). Использование ИИ-помощи на собеседовании может нарушать правила интервьюера или работодателя: приложение не заявляет о невидимости и не гарантирует скрытие от демонстрации экрана.
